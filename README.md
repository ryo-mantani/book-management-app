# 本管理アプリ

## 📌 概要
漫画・書籍を管理するためのWebアプリです。

積読管理や未読率の可視化、
シリーズ管理などを通して、
「買ったのに読んでいない本」を
管理できることを目的としています。

将来的には外部APIと連携し、
最新刊チェックや巻数不足確認にも
対応予定です。

## ✨ 実装予定機能

### 基本機能
- 本の登録
- 編集 / 削除
- 一覧表示
- 検索機能

### 管理機能
- 未読 / 読了管理
- 積読日数表示
- 読了ページ数管理
- シリーズ別管理

### 分析機能
- 未読率表示
- シリーズ別読了率
- 全体統計表示

### API連携（予定）
- バーコード読み取り
- 書籍情報自動取得
- 最新刊との差分表示
- 巻数抜けチェック
